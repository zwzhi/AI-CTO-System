# Project Usage Feedback

此目录保存各外部项目使用 AI CTO System 时产生的、经过授权和脱敏的工作方式反馈。

## 目录约定

```text
<project-id>/PROJECT_USAGE_FEEDBACK.md
```

每个项目默认维护一份主记录。记录模板见 [`templates/PROJECT_USAGE_FEEDBACK_TEMPLATE.md`](../../templates/PROJECT_USAGE_FEEDBACK_TEMPLATE.md)，同步规则见 [`docs/governance/PROJECT_USAGE_FEEDBACK_SYNC_STANDARD.md`](../../docs/governance/PROJECT_USAGE_FEEDBACK_SYNC_STANDARD.md)。

## 边界

- 不保存源码、完整聊天、Secrets 或未授权业务数据；
- 不把单个反馈直接升级为通用规则；
- 不自动修改路由、模型、Skill、Tool、Context、Gate 或 AI CTO Core；
- 没有明确授权和可验证 Evidence 时，不创建项目记录。
