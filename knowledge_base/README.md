# AI CTO Knowledge Base

`knowledge_base/` 是 AI CTO System 治理知识资产的权威目录。知识进入本目录前，必须完成分类、Evidence 标注、可信度判断、质量评估和生命周期登记；目录中存在文件不等于该知识已经允许复用。

目录分类：

- `project_experience/`：项目经验
- `architecture_patterns/`：架构模式
- `engineering_patterns/`：工程模式
- `agent_patterns/`：Agent 设计模式
- `prompt_patterns/`：Prompt 经验
- `bug_solutions/`：Bug 解决方案
- `decisions/`：决策经验
- `failures/`：失败经验
- `business_insights/`：业务洞察

历史目录 `memory/knowledge_base/` 是 Legacy Capture Area，不再接收新的权威 `ACTIVE` Knowledge。历史内容未来必须经过受控提取、验证和注册后，才能迁移到本目录。

本阶段只建立治理结构，不创建真实知识条目，不实现 Agent、RAG、向量数据库或自动检索。
