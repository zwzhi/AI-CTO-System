# Delivery Asset Registry Standard

Startup Script、Deployment Template、Configuration Template、Troubleshooting Template 可作为候选交付资产登记。每项记录 Asset ID、名称、类型、来源项目、版本、适用环境、使用说明、Evidence、质量、限制、License 与状态。资产进入 Knowledge Base 或被复用前，仍须遵循 Knowledge / Technical Asset Governance 的验证、适用范围、安全和 Gate 规则；候选资产不自动成为通用方案。
