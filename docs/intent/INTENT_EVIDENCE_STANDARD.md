# Intent Evidence Standard

未来 Intent 优化记录：`User Input`、Conversation Context、Project Context、Detected Intent、候选 Intent、Confidence、Trigger Decision、Suggested Workflow、Actual Result、Correction、Evidence、适用范围、限制和时间。未捕获字段使用 `NOT_CAPTURED`。

事实、推断、建议和用户纠正必须分开记录。单案例不能训练、部署或固化 Intent 分类规则；只有多个可比较 Evidence、质量评估、用户审批和适用治理审查后，才可提出未来 Evolution。
