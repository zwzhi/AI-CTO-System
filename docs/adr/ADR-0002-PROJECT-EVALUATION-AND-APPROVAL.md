# ADR-0002：项目评分与立项门禁分离

- 状态：Accepted
- 日期：2026-07-13
- 决策者：AI CTO System 项目创建者、AI CTO

## 背景

单一总分便于比较项目，但高分可能掩盖合规、安全、数据、许可证或证据不足等不可接受风险。项目分数也不能表达结论证据的可信程度。

## 决策

项目采用 100 分制评估，同时独立记录：

- 各维度评分及判断依据
- Confidence 等级
- 风险红线
- Research 与 Evaluation 完成状态
- 用户立项确认

总分只生成优先级建议，不自动批准立项。任何强制门禁未通过时，项目不得进入 DESIGN。

## 选择理由

该设计兼顾项目间可比较性与决策安全性，防止以高商业价值抵消不可接受风险，也避免把低可信推测包装为高确定性结论。

## 替代方案

- 仅按总分决策：简单，但可能掩盖红线和证据缺口。
- 仅做定性判断：灵活，但难以比较项目优先级和复盘评分偏差。

## 后果

- 每次评估需要同时产出分数、Confidence、风险和门禁结果。
- 评分达到建议阈值后仍可能因红线、低 Confidence 或文档缺失被阻断。
- 后续应通过真实项目回测校准评分锚点与阈值。
