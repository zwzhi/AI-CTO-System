# 技术债治理标准

## 1. 目的

本标准将技术债从模糊抱怨转化为可识别、可评估、可排期、可验证的治理对象。技术债可以被暂时接受，但不得被隐藏、无限延期或通过删除记录视为解决。

## 2. 技术债来源

| 来源 | 典型表现 | 主要证据 |
|---|---|---|
| 代码质量 | 重复、复杂度、可读性、错误处理和模块边界问题 | 静态分析、Review、缺陷与变更成本 |
| 架构问题 | 高耦合、单点、隐式依赖、数据流不清和扩展受限 | Architecture、Incident、性能与容量数据 |
| 依赖过期 | EOL、漏洞、兼容性、License 或供应商锁定 | SBOM、版本公告、安全扫描和升级试验 |
| 测试不足 | 核心路径、失败路径、回归或 Evidence 缺失 | 测试矩阵、覆盖、逃逸缺陷和变更失败率 |
| 性能问题 | 延迟、吞吐、资源、容量或成本持续偏离目标 | 监控、压测、成本与容量趋势 |
| 安全问题 | 密钥、权限、数据、日志、供应链或响应控制不足 | Security Review、Incident 和审计证据 |

Incident、Postmortem、Code Review、用户反馈、依赖扫描、健康检查和 AI 能力趋势都可以创建 Debt，但必须指向具体事实而不是主观判断。

## 3. Debt Record 必填字段

每项技术债必须包含：

- Debt ID；
- 标题与问题描述；
- 来源类别与发现来源；
- 首次发现时间、当前基线和 Evidence；
- 影响，包括用户、业务、开发效率、可靠性、安全、数据、成本和扩展；
- 风险等级及依据；
- 修复成本、资源、依赖与机会成本；
- 建议处理时间、最迟复核时间和触发条件；
- 建议方案、替代方案、迁移与回滚考虑；
- Owner、状态、关联 Task / Incident / Bug / Proposal / ADR；
- 关闭标准、验证方法和关闭 Evidence。

## 4. 风险等级

| Risk | 定义 | 处置要求 |
|---|---|---|
| `CRITICAL` | 已触发或即将触发重大安全、数据、可用性或不可恢复风险 | 立即控制；按 Incident / Security 流程处理，不得仅留在 Debt Backlog |
| `HIGH` | 明显提高核心变更失败、故障或维护中断概率 | 优先进入近期计划；必须有 Owner 和期限 |
| `MEDIUM` | 造成稳定成本、效率或质量损失，但影响可控 | 纳入维护路线图并周期复核 |
| `LOW` | 局部、低频或机会型改进 | 进入 Backlog，按价值和成本排序 |

风险等级不等于维护 Priority。风险描述后果与概率，Priority 决定当前排程；二者必须分别记录。

## 5. 状态与流程

技术债状态只允许：`REGISTERED`、`ASSESSED`、`SCHEDULED`、`IN_PROGRESS`、`VALIDATING`、`CLOSED`、`ACCEPTED_TEMPORARILY`、`SUPERSEDED`。

`发现 → 登记 → 评估 → 排序 → 计划 → 执行 → 验证 → 关闭`

- `ACCEPTED_TEMPORARILY` 必须记录授权人、理由、风险、有效期、监控、停止条件和复核日期；到期自动回到 `ASSESSED`，不能无限续期。
- `SUPERSEDED` 只表示由另一 Debt、Proposal 或架构决策接管，必须双向关联，不能隐藏未解决影响。
- 只有目标风险已消除或降至批准阈值，并有测试、监控或运行 Evidence 时才能 `CLOSED`。

## 6. 排序与债务预算

排序至少考虑风险、用户 / 业务影响、故障与反馈频率、修复成本、延迟成本、阻塞的未来工作、可逆性和可验证性。每个维护周期必须为高风险债务保留明确容量，记录计划与实际差异。

禁止只按“最容易修”排序，也不得用新增功能长期挤占已经触发红线的债务。连续两个维护周期没有下降的 HIGH / CRITICAL 债务、跨越多个核心模块的架构债或显著阻塞战略目标的债务，必须评估是否触发 Evolution Proposal。

## 7. 执行和验证

债务处理必须遵守适用的 Requirement、Design、ADR、Task、TDD、Change Impact、Review、Testing 和 Release Gate。重构不能以“不改变功能”为理由跳过回归、安全或数据验证。

关闭前必须比较处理前后基线，证明风险、复杂度、成本、性能、测试或维护性达到预先定义的验收标准，并更新 Architecture、ADR、Runbook、PROJECT_STATE、PROJECT_MEMORY 和知识库中受影响内容。
