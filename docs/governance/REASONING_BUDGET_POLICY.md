# Reasoning Budget Policy

## 推理等级

| 等级 | 名称 | 适用范围 | 默认任务等级 |
|---|---|---|---|
| R0 | 直接响应 | 已知事实、普通咨询、无需项目判断 | Level 0 |
| R1 | 简单分析 | 已确认范围的局部文档 / 配置修改 | Level 1 |
| R2 | 结构化分析 | 常规工程任务、影响明确的多步骤工作 | Level 2 |
| R3 | 深度规划 | 模块级变化、设计权衡、跨文档影响 | Level 3 |
| R4 | CTO 级推理 | 新项目、重大架构、跨项目资源 / 风险决策 | Level 4 |

## 规则

1. 默认选择满足质量、安全和可追溯性的最低充分推理等级。
2. 未知影响、红线、冲突、不可逆操作、跨层关系、复杂安全 / 数据风险可升级推理等级。
3. 更高等级不等于自动获得执行权限，也不能覆盖 Gate、ADR、安全、权限或用户当前指令。
4. 低等级任务不应因固定模板、历史惯例或流程完整性自动升至 R3 / R4。
5. Execution Plan 记录建议等级、理由、升级条件与 Confidence；内部实际推理量不可观测时标 `NOT_CAPTURED`。
